## للمساهمين ومراجعي الكود

التقنيات المستخدمة:

<div dir="rtl">

| الموقع | المسؤولية |
| --- | --- |
| `src/lib/commands.ts` | أوامر المجال والتحقق والتزامن والتبعيات والمراجعات |
| `src/lib/permissions.ts` | الصلاحيات المدمجة والمخصصة |
| `src/lib/auth.ts` | إعداد المصادقة وتكامل الجهات |
| `src/db/schema.ts`، `drizzle/` | نماذج البيانات العلائقية والترحيلات الإضافية |
| `src/db/workspace.ts` | تحميل لقطة مساحة العمل وحفظ السجلات المتغيرة |
| `src/app/api/` | عمليات المهام والملفات والإشعارات والقوالب والتدقيق ومساحات العمل بحسب الصلاحيات |
| `src/components/` | الشاشات والنماذج وعناصر الواجهة المشتركة |
| `src/messages/en.json` | المصدر الأساسي للنصوص الإنجليزية |
| `src/messages/ar.json`، `src/lib/i18n.ts` | الترجمات العربية وتحديد اللغة والعودة إلى الإنجليزية |
| `tests/`، `scripts/integration.mjs`، `e2e/` | فحوصات المجال وقاعدة البيانات والمتصفح |

تبدأ نصوص الواجهة في القاموس الإنجليزي. لإضافة لغة، أنشئ قاموسًا بمفاتيح مطابقة، وسجّله في ملف إعداد اللغات، وحدّد اتجاهه. عند غياب ترجمة تُستخدم الإنجليزية. تبقى نصوص المهام والمشاريع التي يكتبها المستخدم بلغتها الأصلية.

تعمل أوامر مساحة العمل تحت قفل على سجل المساحة، وتحفظ السجلات المتغيرة وإدخال التدقيق ضمن معاملة واحدة. تفرض المفاتيح الخارجية المركبة حدودًا مهمة بين المساحات. يستخدم الجدول واللوحة استعلامات مقسّمة، وتعتمد تحليلات الإنجاز على التجميع داخل قاعدة البيانات. ما زالت تفاصيل التحرير ولوحة الملخص والتقارير الشهرية الأصلية وإعدادات التخطيط تعتمد على لقطة مساحة العمل. راجع ملاحظات التشغيل قبل تقدير متطلبات الاستضافة.

لتشغيل الفحوصات:

</div>

```bash
npm run typecheck
npm test
npm run format:check
npm run build
```

تشمل فحوصات النطاق الحالي فحص الأنواع، و٣٧ اختبارًا للمجال والترجمة وفحص الملفات، وترحيلات قاعدة البيانات وتدفقات التكامل، وبناء الإنتاج، و٧ اختبارات متصفح تشمل إدارة العمل، والتنقل العربي على الجوال، وإعداد الحساب ومفتاح المرور، وإمكانية الوصول في الملخص، ومسار التخطيط حتى لوحة المهام، والحقول المخصصة والوقت ومفاتيح التقويم والتاريخ الهجري. تُشغّل الفحوصات آليًا عند التغييرات. تستخدم بيانات الاختبار حسابات وهمية وبريدًا محفوظًا محليًا.

## مكونات الواجهة

تستخدم النماذج مكونات شادسن المبنية على بيس يو آي للمدخلات والقوائم ومربعات التحديد. يدعم مكوّن الاختيار المشترك القيم المفردة والمتعددة مع إرسالها ضمن النموذج. توجد قائمة اللغة في الشريط العلوي، وخيار التاريخ الهجري في إعدادات الحساب.

تستخدم التحليلات مخططات شادسن مع جداول للأرقام، وتُحمّل مكتبة المخططات عند فتح التحليلات. ألوان المخططات متغيرات في ملف التنسيق العام. تُترجم الحالات الافتراضية عند عرضها، وتبقى أسماء الحالات المخصصة ومحتويات المهام كما كتبها المستخدم، دون تعديل قاعدة البيانات.

تُحمّل لوحة المهام في طلب واحد، بحد أقصى ٢٥ مهمة لكل حالة، مع تطبيق صلاحيات الاطلاع نفسها. يُحمّل المزيد لكل عمود عند الطلب. تشترك طلبات القراءة المتطابقة والمتزامنة في اتصال واحد، وتُحمّل الفلاتر المحفوظة عند فتح قسمها. تظل بيانات مساحة العمل والإشعارات وقائمة مساحات العمل موارد مستقلة، لذلك وجود عدة طلبات مختلفة أمر متوقع.

استفاد تنظيم الواجهة من مشروعي [Plane](https://github.com/makeplane/plane) و[Worklenz](https://github.com/Worklenz/worklenz)، دون نسخ شيفرتهما. توجد رخصة مكونات شادسن المعدّلة في [إشعارات الطرف الثالث](../THIRD_PARTY_NOTICES.md).
