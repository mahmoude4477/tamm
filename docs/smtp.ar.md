# إعداد إرسال البريد

[العودة إلى الملف التعريفي](../README.ar.md) · [English](smtp.md)

يستخدم تم إعداد البريد نفسه للتحقق من الحساب واستعادة كلمة المرور والدعوات وإشعارات المهام التي يفعّلها العضو. تُحفظ بيانات الدخول في بيئة الخادم؛ لا تضعها في المستودع العام أو واجهة المتصفح.

## ما البيانات المطلوبة؟

اطلب من مسؤول البريد: اسم خادم الإرسال أو عنوانه، ورقم المنفذ، وطريقة تشفير الاتصال، وعنوان المرسِل، واسم المستخدم وكلمة المرور إن كانا مطلوبين. قد يكون اسم المستخدم عنوان البريد نفسه. بعض المزوّدين يحتاجون كلمة مرور تطبيق أو خادم ترحيل معتمد. وقد يسمح الخادم الداخلي بالإرسال بناءً على عنوان خادم التطبيق دون اسم مستخدم وكلمة مرور.

## مثال شائع

ضع القيم الفعلية في ملف البيئة التالي:

</div>

`.env.local`

```dotenv
MAIL_TRANSPORT=smtp
MAIL_FROM="Tamm <notifications@example.com>"
SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_SECURE=false
SMTP_REQUIRE_TLS=true
SMTP_USER=notifications@example.com
SMTP_PASSWORD=
```

<div dir="rtl">

أدخل كلمة المرور سرّيًا. في المنفذ ٥٨٧ يبدأ الاتصال ثم يُرقّى إلى اتصال مشفّر؛ الإعداد أعلاه يشترط نجاح الترقية.

إذا طلب المزوّد المنفذ ٤٦٥، غيّر الإعدادين التاليين:

</div>

```dotenv
SMTP_PORT=465
SMTP_SECURE=true
```

<div dir="rtl">

## خادم داخلي أو عنوان شبكة

استخدم القيم التي يزوّدك بها مسؤول الشبكة. إن كان الخادم لا يتطلب مصادقة، اترك اسم المستخدم وكلمة المرور فارغين معًا. وجود عنوان داخلي لا يعني تلقائيًا السماح بالإرسال.

عند الاتصال بعنوان شبكة، اضبط أيضًا اسم الخادم الموجود في شهادة التشفير:

</div>

```dotenv
SMTP_HOST=192.0.2.10
SMTP_TLS_SERVERNAME=mail.example.com
```

<div dir="rtl">

إذا كانت الشهادة صادرة عن جهة داخلية، أضف شهادة الجهة إلى إعداد الثقة في بيئة التشغيل. لا تعطّل التحقق من الشهادات. استخدم المنفذ ٢٥ أو ألغِ اشتراط ترقية التشفير فقط إذا طلب مسؤول الشبكة ذلك لخادم ترحيل موثوق.

</div>

`NODE_EXTRA_CA_CERTS` · `SMTP_REQUIRE_TLS`

## اختبار الإعداد

</div>

```bash
npm run mail:check
```

<div dir="rtl">

يفحص هذا الأمر الاتصال والمصادقة دون إرسال رسالة. نجاحه لا يضمن قبول كل عنوان مرسِل أو وصول الرسالة إلى كل صندوق بريد. أعد تشغيل التطبيق والعامل بعد تغيير البيئة. يجب تشغيل العامل المجدول لإرسال تذكيرات المواعيد وإشعارات المهام؛ رسائل الحساب والدعوات يرسلها التطبيق مباشرة.

في التطوير، يحفظ وضع الملفات الرسائل محليًا ولا يرسلها، حتى لو كانت بيانات خادم البريد مضبوطة. غيّر وضع النقل إلى الإرسال الفعلي عند النشر:

</div>

`MAIL_TRANSPORT=file` → `MAIL_TRANSPORT=smtp`
