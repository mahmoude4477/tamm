تم نظام مفتوح المصدر لإدارة مهام ومشاريع الفرق الداخلية. يساعدك على تخطيط العمل، وإسناده، وتتبع نقله بين الأعضاء، ومراجعة النتائج بواجهة واضحة. تصف التقارير الشهرية الإنجاز وعبء العمل دون منح الموظفين درجات تقييم اعتباطية.

**يضيف الإصدار ١٫٥ المهام المتكررة، والمعالم، وتخطيط الطاقة الاستيعابية، وتحليلات الإنجاز.** تستخدم النسخة التجريبية بيانات وهمية، ولا تتضمن معلومات شخصية أو بيانات دخول لجهات أو سجلات إنتاجية.

![واجهة تم بمشاريع ومهام وهمية](docs/preview.png)

## ما الذي يمكنك إنجازه؟

| المجال | الميزات المتاحة |
| --- | --- |
| الحسابات | التحقق من البريد واستعادة الحساب، تعديل الملف الشخصي، إدارة الجلسات، المصادقة الثنائية ومفاتيح المرور الاختيارية |
| الهيكل التنظيمي | مساحات عمل متعددة، دعوات، أقسام، فرق، عضوية في أكثر من فريق، أدوار مخصصة، وتعطيل الأعضاء |
| المشاريع | المالك والمدير، المواعيد، الأولويات، مستوى الظهور، الملفات، النشاط، والأرشفة والاستعادة |
| المهام | مهام فرعية، قوائم تحقق، تبعيات، مهام مرتبطة، عدة مسؤولين، الجهد، الوسوم، ومسارات عمل قابلة للتخصيص |
| المراجعة | تقديم العمل للاعتماد، الموافقة، الإعادة للتعديل، أسباب نقل المهام، وموافقة اختيارية على النقل |
| التعاون | أوصاف وتعليقات منسقة، ردود، إشارات للأعضاء، متابعون، ملفات، وصندوق إشعارات |
| طرق العرض | لوحة مهام، جدول قابل للتخصيص، تقويم يومي وأسبوعي وشهري، مهامي، لوحة المدير، فلاتر محفوظة، وبحث |
| التقارير | مؤشرات شهرية، مقارنة بالشهر السابق، فلاتر حسب الصلاحيات، وتصدير بصيغ الجداول والمستندات |
| الإدارة | إدارة الأعضاء والأدوار، إعداد سير العمل، الإعدادات، سلة المحذوفات، وسجل تدقيق قابل للتصفية |
| التخطيط | مهام متكررة، معالم ونسب إنجازها، طاقة استيعابية أسبوعية، وتحليلات الإنجاز وصحة المشاريع |
| اللغات | الإنجليزية افتراضيًا، العربية، اتجاه تلقائي، والعودة إلى الإنجليزية عند غياب ترجمة |

## التشغيل محليًا

المتطلبات:

</div>

**Node.js 22+ · PostgreSQL 16+ · npm**

```bash
git clone https://github.com/mahmoude4477/tamm.git
cd tamm
npm ci
cp .env.example .env.local
```

<div dir="rtl">

اضبط رابط قاعدة البيانات، وعنوان التطبيق، وسر المصادقة الذي تولّده محليًا في ملف البيئة التالي. لا تضف ملف البيئة إلى المستودع.

</div>

`.env.local`

```dotenv
DATABASE_URL=
BETTER_AUTH_URL=
BETTER_AUTH_SECRET=
```

<div dir="rtl">

ولّد السر، ثم طبّق ترحيلات قاعدة البيانات وشغّل التطبيق:

</div>

```bash
node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"
node --env-file=.env.local node_modules/drizzle-kit/bin.cjs migrate
npm run dev
```

<div dir="rtl">

افتح [التطبيق المحلي](http://localhost:3000). في بيئة التطوير تُحفظ رسائل البريد في مجلد محلي؛ افتح الرابط داخل الرسالة للتحقق من الحساب أو تجربة الاستعادة. في بيئة النشر استخدم خادم بريد.

</div>

`.data/mail` · SMTP

<div dir="rtl">

| المسار | الغرض |
| --- | --- |
| `/` | نسخة تجريبية وهمية؛ تختفي التغييرات عند تحديث الصفحة |
| `/login` | تسجيل الدخول أو إنشاء حساب عندما يكون التسجيل مفعّلًا |
| `/workspace` | مساحة العمل ذات البيانات المحفوظة |
| `/board` | تحميل البيانات الأساسية أولًا، ثم ٢٥ مهمة لكل حالة، مع تحميل المزيد عند الطلب |
| `/admin` | إعدادات الحساب وإدارة مساحة العمل بحسب الصلاحيات |
| `/invite` | قبول الدعوة باستخدام البريد المدعو |
| `/forgot-password`، `/reset-password` | استعادة الحساب |
| `/verify-2fa` | التحقق بتطبيق المصادقة أو رمز الاسترداد |
| `/api/health` | التحقق من جاهزية قاعدة البيانات |

أنشئ مساحة عمل، وأضف مشروعًا، وادعُ الفريق من الإدارة. يتيح مبدّل مساحات العمل استخدام حساب واحد في عدة جهات.

لتفاصيل البريد، والتشغيل بالحاويات، والنسخ الاحتياطي، والتحقق من الاستعادة، وتعليق الحسابات، والنشر، راجع [دليل التشغيل بالإنجليزية](docs/operations.md).

## قائمة إنجاز الإصدار الأول

العنصر المحدد منفّذ ومشمول بفحوصات الإصدار. العناصر غير المحددة ما زالت ضمن العمل المتبقي.

### الحسابات والهيكل التنظيمي

- [x] الحسابات والجهات والفرق والتبديل بين مساحات العمل.
- [x] التحقق من البريد، واستعادة كلمة المرور، وقبول الدعوات وانتهاؤها وإلغاؤها.
- [x] تعديل الملف الشخصي، وروابط الصور، وإلغاء الجلسات، والمصادقة الثنائية، ومفاتيح المرور.
- [x] الأقسام، والمديرون، والمسميات الوظيفية، وتعدد الفرق، والأدوار المخصصة، وتعطيل الأعضاء.
- [x] تعليق الحساب على مستوى التثبيت عبر أمر المشغّل الموثّق في سجل التدقيق.

### العمل والتعاون

- [x] تعديل المشاريع وملكيتها ومواعيدها وأولوياتها وظهورها وملفاتها، وأرشفتها واستعادتها.
- [x] المهام والمهام الفرعية المستقلة وقوائم التحقق والتبعيات والروابط ومراجع التكرار.
- [x] عدة مسؤولين عن المهمة، وأنواع المهام، والجهد المتوقع والفعلي، والوسوم.
- [x] تخصيص الحالات وترتيبها والانتقالات المسموحة، والاعتماد والإعادة للتعديل.
- [x] سجل الإسناد وأسباب النقل وقواعد النقل بين أعضاء الفريق والتفويض بموافقة المدير.
- [x] قوالب المهام والمشاريع مع المهام الفرعية وقوائم التحقق.
- [x] تنسيق النصوص، والتعليقات وتعديلها وحذفها، والردود والإشارات والمتابعون.
- [x] التحقق من المرفقات، وتنزيلها بحسب الصلاحيات، ومعاينة الصور، والحذف القابل للاستعادة.
- [x] صندوق الإشعارات وحالة القراءة والتفضيلات وتذكيرات قرب الموعد والتأخر.
- [x] نشاط المهام والمشاريع وسجل تدقيق مستقل قابل للتصفية.

### طرق العرض والتقارير

- [x] اللوحة والجدول والتقويم ومهامي، وعروض اعتماد المدير وعبء العمل.
- [x] البحث في المهام والمشاريع والأشخاص والفرق.
- [x] الفلاتر المتقدمة والعروض المحفوظة وروابط الفلاتر القابلة للمشاركة والعمليات الجماعية.
- [x] فرز الجدول وإظهار أعمدته وتغيير حجمها بلوحة المفاتيح وتقسيم النتائج من الخادم.
- [x] تقارير شهرية بحسب الصلاحيات، ومقارنات الأشهر، ومدة الإنجاز، ومؤشرات إعادة الفتح والإعادة للتعديل، والتصدير.
- [x] قاموسا الإنجليزية والعربية، واللغة البديلة، وإعداد المنطقة الزمنية، واتجاه العرض العربي.
- [x] ترحيلات إضافية وتعليمات النشر وتوثيق النسخ الاحتياطي والاستعادة.
- [x] الفحوصات النهائية للمتصفح وإمكانية الوصول وقاعدة البيانات للإصدار الأول.

## للمساهمين ومراجعي الكود

التقنيات المستخدمة:

</div>

Next.js App Router · React · TypeScript · Tailwind CSS · shadcn/ui with Base UI · Better Auth · PostgreSQL · Drizzle · Zod · TanStack Table

<div dir="rtl">

| الموقع | المسؤولية |
| --- | --- |
| `src/lib/commands.ts` | أوامر المجال والتحقق والتزامن والتبعيات والمراجعات |
| `src/lib/permissions.ts` | الصلاحيات المدمجة والمخصصة |
| `src/lib/auth.ts` | إعداد المصادقة وتكامل الجهات |
| `src/db/schema.ts`، `drizzle/` | نماذج البيانات العلائقية والترحيلات الإضافية |
| `src/db/workspace.ts` | تحميل لقطة مساحة العمل وحفظ السجلات المتغيرة |
| `src/app/api/` | عمليات المهام والملفات والإشعارات والقوالب والتدقيق ومساحات العمل بحسب الصلاحيات |
| `src/components/` | الشاشات والنماذج وعناصر الواجهة المشتركة |
| `src/messages/en.json` | المصدر الأساسي للنصوص الإنجليزية |
| `src/messages/ar.json`، `src/lib/i18n.ts` | الترجمات العربية وتحديد اللغة والعودة إلى الإنجليزية |
| `tests/`، `scripts/integration.mjs`، `e2e/` | فحوصات المجال وقاعدة البيانات والمتصفح |

تبدأ نصوص الواجهة في القاموس الإنجليزي. لإضافة لغة، أنشئ قاموسًا بمفاتيح مطابقة، وسجّله في ملف إعداد اللغات، وحدّد اتجاهه. عند غياب ترجمة تُستخدم الإنجليزية. تبقى نصوص المهام والمشاريع التي يكتبها المستخدم بلغتها الأصلية.

تعمل أوامر مساحة العمل تحت قفل على سجل المساحة، وتحفظ السجلات المتغيرة وإدخال التدقيق ضمن معاملة واحدة. تفرض المفاتيح الخارجية المركبة حدودًا مهمة بين المساحات. يستخدم الجدول واللوحة استعلامات مقسّمة، وتعتمد تحليلات الإنجاز على التجميع داخل قاعدة البيانات. ما زالت تفاصيل التحرير ولوحة الملخص والتقارير الشهرية الأصلية وإعدادات التخطيط تعتمد على لقطة مساحة العمل. راجع ملاحظات التشغيل قبل تقدير متطلبات الاستضافة.
